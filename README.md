# PRCP-1001 Rice Leaf Disease Detection

The primary submission is [RiceLeaf_Disease_Detection.ipynb](./RiceLeaf_Disease_Detection.ipynb), as required by the project brief. It downloads the public dataset, explores and validates it, compares a CNN with/without augmentation and an ImageNet-pretrained MobileNetV2, evaluates on a held-out split, and documents limitations and challenges. [app.py](./app.py) provides a Streamlit image-classification UI using the saved MobileNetV2 model.

## Setup

Use Python 3.10-3.12 and install the project dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
jupyter notebook
```

Run all cells in `RiceLeaf_Disease_Detection.ipynb`. The notebook downloads the dataset ZIP into `data/` and stores trained models, metrics, and plots in `outputs/`. Both folders are generated at runtime. An internet connection is needed for the dataset and pretrained MobileNetV2 weights on their first download. The notebook uses a small default image size, batch, and epoch count to run on a constrained CPU; increase these settings only when memory and compute allow.

The included notebook has been executed end-to-end on the available CPU runtime (Python 3.9 / TensorFlow 2.11). That runtime is older than the recommended setup above, so retraining with the listed dependencies may produce different scores. TensorFlow is capped below 2.20 to keep its protobuf requirements compatible with Streamlit.

## Run the Streamlit app

The app uses the trained model and class metadata generated by the notebook. It includes a prominent rice mark, an example leaf image from the dataset, an upload-specific prediction summary, and separate expandable model details. From this folder, with the same Python environment used to train the model:

```powershell
python -m streamlit run app.py
```

Streamlit opens the app in your browser. Upload a JPEG or PNG image up to 10 MB to view the model's class scores. If `outputs/` does not contain the saved model and `image_analysis.csv`, run the notebook first. The UI reports model scores, not calibrated probabilities or diagnoses.

For a fresh Python 3.10-3.12 environment, install `requirements.txt`, run the notebook to train the model in that environment, then start the app. The model currently included in this folder was trained with TensorFlow 2.11 on Python 3.9; in that legacy environment, keep its TensorFlow/protobuf versions and use a compatible Streamlit release instead of upgrading packages from `requirements.txt`.

## Dataset labels

The brief's introductory text mentions leaf blast, but its explicit class list is Leaf smut, Brown spot, and Bacterial leaf blight. The notebook discovers class names from the downloaded directory tree and prints the observed names and counts instead of assuming labels. The supplied archive contained 119 readable images in this run: 40 Bacterial leaf blight, 40 Brown spot, and 39 Leaf smut, rather than the stated 120/40-per-class.

## Scope and limitations

The notebook includes a stratified 60/20/20 split and reports test accuracy, macro precision/recall/F1, per-class metrics, confusion matrices, and training curves. With just 119 images, these estimates are highly uncertain and do not support production claims. Collect more independently sourced, expert-verified data and use a separate external test set before considering deployment.

## Project overview and results

The workflow loads and validates the rice-leaf images, resizes them to a consistent input shape, and splits the original images into training, validation, and test sets before applying training-only data augmentation. It compares a compact CNN without augmentation, the same CNN with augmentation, and a frozen ImageNet-pretrained MobileNetV2 with augmentation. The Streamlit interface uses the saved MobileNetV2 model to return model scores for an uploaded leaf image.

| Model | Test accuracy | Macro precision | Macro recall | Macro-F1 |
|---|---:|---:|---:|---:|
| MobileNetV2 + augmentation | 79.2% | 80.3% | 79.2% | 78.9% |
| CNN without augmentation | 33.3% | 11.1% | 33.3% | 16.7% |
| CNN with augmentation | 33.3% | 11.1% | 33.3% | 16.7% |

These are measured results from one run on a **24-image held-out test set** (8 images per class), using a low-resource CPU configuration of 96 × 96 pixels and 3 training epochs. They are useful for an educational model comparison, but the test sample is far too small to establish reliable field or production performance. The measured MobileNetV2 result is a candidate for further evaluation, not a validated production recommendation. Scores can vary when the project is retrained.
